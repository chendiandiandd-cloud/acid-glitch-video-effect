# 分层验收：五类背景、人物保留与两种回归

## 授权与状态
人物局部获认可，背景与建筑仍未通过，整体renderer待视觉验收。当前用户已明确授权每次优化后交付一条新4秒效果测试，默认使用当前指定/最近测试素材并复用已有分割缓存。只有用户明确暂停、只改不出片或撤回授权才做无媒体验证；后续暂停优先，不能用旧调优规则拒绝有效持续约定。

检查顺序：背景状态是否对 → 局部原景与整画面回闪是否分开 → 人物/区域保护 → 印刷块面/填色/替换大形 → 颗粒/故障/随动 → 格式性能。不能用“源建筑一直可辨”作通用通过条件。

配方tests检查真实数组逻辑，不给伪精确语义或相似度。双色仅窄窗网点，墨填色暗部稳定；液化检查少数宽带回卷/分叉而非纯轮廓线；横断检查当前印刷源结构局部拉长、源/目标保护、无整屏均匀条纹。单次优化仅出一条新测试，不因检查发现不足无限再渲染。source与完整natural gate保持不同职责，人物可靠core不变，软边只混新人物层/新背景。

## 五类背景专项
1. source：背景/允许近景可较自然，人物仍黄黑；不能因此开启whole-frame gate。
2. duotone：建筑暗部/窗格/轮廓形成深墨，亮部是黄/橙等平面，窄过渡网点；保留大面积摄影渐变是偏离。
3. ink_colorfield：深墨建筑结构叠在彩色填充上，墨色不被场洗淡；不是给摄影建筑加紫绿滤镜。
4. liquid_replace：合法背景含建筑可被大尺度二维液化替换，建筑消失允许；“保护建筑”造成只一角流体为偏离。
5. horizontal_glitch：有强横向拉伸、断裂、条带/块故障与彩色变化；不是持续平滑小幅扭曲，不用整屏均匀雪花代替。

状态可分区共存，8张截图不能给出唯一播放顺序/持续时间。不能机械均匀轮换五类或伪填42帧预设。完整证据见background-structure.md；对图52不声称建筑全纯黑无任何细节。

## 两种回归关卡
- 局部背景source：背景/允许N回到当前原景，人物强处理保持；与截图24的可见区别对照，不写截图文件时间作PTS。
- 整画面natural_gate：按F00基准与F02/F14/F17/F34/F38/F41，人物、近景和背景共同复色；仅关闭背景不算整画面通过。
- 每观测格0.125秒、不等间隔；高fps检查实际PTS采样，不只插1帧原色。低fps漏采记录，不静默改fps/脉宽。
- F06/F22/F25/F29的partial不能当整画面回闪。自然分支可有校准残余，不要求完全无处理。
- 源PTS持续推进，无参考证据不加入倒跳/重放。长片循环是适配推断，不证明原参考后续节奏。

## 人物与区域回归
保留可靠人物核心的印刷、配色、网点与断墨风格。用户已否定分割，允许修正mask/边缘/跟随；strong帧只要求可靠且alpha=1的核心与baseline逐像素相同，软边用独立人物印刷与新背景合成，不能冻结混入旧背景的非零支撑。自然gate另与既有完整自然分支对照。

缺少实际基准时写“保护数值逻辑通过，实片人物基准待建立”。多人保留全部实例，小人/边缘/遮挡检查；传统动物/建筑候选不声称语义识别准确。

A建筑不是永久保护区；E可包括无天空/室内背景。近景N是否回归需单独允许，不悄悄解除人物/文字/产品保护。

## 纹理与动态
背景细密印刷颗粒、窄过渡网点、锐利断墨/细长划痕共同组织块面，不仅末尾少量白点。天空/填色局部彩噪可符合参考；无差别整屏RGB雪花仍不算分层故障。黑/深墨不能洗灰，黄亮面不能成砂纸，乳白云/霉斑为偏离。

液化看二维折叠/回卷/涡旋大形及内部曲率；机械平行液化波纹偏离，但故障状态可以有横向条带。原参考同尺寸并排看结构，再各自完整播放看内容随动、状态跳动、mask漂移和切镜；接触表不证明动态正确。

## 泛化、指标和交付
实际样本分别覆盖人像/多人、动物、产品、风景、室内、动画/文字，横竖屏、暗光、快运动、切镜与长片。未测试保持“策略已定义，视觉待验证”，不能单片推导全部适配。

数组测试只证明状态选择/双色稳态/墨区填色/显式替换、区域保护和时间路由；不能给视觉相似度。wear_region_contrast不是美学目标，覆盖/粒径/损坏密度须参考校准。

复用人物缓存，背景独立计算；有生成授权才估算/渲染。真MP4/H.264保留约定时长、显示比例与原音轨，检查旋转、音画同步、首尾与解码。格式通过不代表风格通过，数值通过不代表完整renderer成功。

## 防止横向接缝复发的回归
- 检查实际renderer接入区域工具，不能只有文档禁止固定分区、实现仍是固定高度。
- 合成数组复现旧固定行裁切，确认mask长横向硬跳变诊断能报告；改为明确full_background后无该人为边界，横屏/竖屏均检查。
- 人物移动的合成mask每次重建E：旧位置解除保护，新位置完整保护；可靠且alpha=1的核心与基准逐字节相同；软边不得复用旧背景，显式保护区仍不变。
- explicit保留输入软权重与E外限制；不静默扩张、不用模糊抹去诊断。
- 局部source人物仍强处理；whole-frame natural_gate完整切自然分支。非法mask/参数应拒绝，不无声降级。
- 无媒体测试不证明当前实片接缝视觉已通过；当前持续测试约定有效时优化后交付一条新4秒片，再并排与完整播放核验。横向故障条带是效果组织，不等于E区域硬切。

## 人物边缘与霓虹专项
人物核心保护与分割合格分开：核心byte相同不证明mask准确。用人物与新背景反差明显的帧检查帽沿、镜框、肩膀、小人及孔洞；软边不得有旧背景硬壳或大光晕，alpha=0必须是新背景；改变approved不能改变非核心合成。逐帧检查运动与遮挡，不用少数静帧宣称跟随通过。

霓虹专项检查有限主色的大尺度不规则折叠/回卷、深墨保留和状态差异；循环彩虹、等距发光细带、整屏随机RGB和密集平行波纹仍是偏离。与旧失败片并排，记录改善及剩余问题，不能凭代码参数变化说更美。每次优化完成交付一条新的4秒MP4，持续测试约定仍有效。
