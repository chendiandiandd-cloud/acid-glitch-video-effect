# 按需背景校准：五类状态与区域契约

仅风格调优、参考复核或区域故障时读。正常处理不重看所有截图，不自动生成测试片；本次测试长度以用户要求为准。

## 保留约束
背景不是“摄影染色+小幅扭曲”单一方案；可提墨结构，不要求所有强状态都保留摄影明暗或建筑。人物保留可靠alpha=1核心的认可黄黑/网点/断墨；错误mask与软边可修，软边混独立人物层/新背景，不能冻结混旧背景的非零支撑。整画面回闪按原42格/当前源PTS保持，整体renderer尚未获视觉认可。

## 五类数组职责
| state | 实现与视觉边界 |
| --- | --- |
| source | 当前原景背景，允许轻微校准残余；人物仍强处理 |
| duotone | 源明暗转深墨/亮平面、窄过渡网点，不保留大面积摄影渐变 |
| ink_colorfield | 原墨结构压彩色填充，墨色不被洗淡；不是摄影紫绿滤镜 |
| liquid_replace | 显式二维液化帧替换合法背景，建筑可消失，先大形回卷/折叠 |
| horizontal_glitch | 显式局部横拉/切裂帧，允许强破坏源结构，不用均匀雪花代替 |

## 合成与区域
主体H、建筑墨候选A、远景D、天空K、近景N、可编辑E分开；K可空，A不是永久保护区，E不只蓝天。source背景、明确允许的N恢复、whole-frame natural_gate是三个控制；gate选择同PTS完整自然分支，之后不叠黄黑。
人物软边修复使用matte；可靠核心保基准，其余混新人物/背景。E外关键文字/产品/近景不悄悄解除保护，全背景仅明确艺术范围，不是准确语义分割。
禁止固定画面高度裁E（如y<height*.49），不靠移横线或整片模糊修接缝。`background_regions.py`的full_background排除P>0、explicit保留允许mask软权重；当前软边修复可用可靠核心作P再matte，旧无污染背景-only路径才冻结非零支撑。horizontal_cut_rows诊断mask长横向硬跳变，不评分图像，不否定艺术横断。
源候选随当前帧更新；缓存按新露出/遮挡/运动失效，切镜清空间历史但不重置全局回闪。无天空/室内/非人素材按 [适配策略](adaptation.md) 选范围，不调用未授权额外语义模型。

## 纹理与色场
先深墨/亮块，再窄过渡网点与锐利细碎断墨/划痕；天空/填色可局部密集彩颗粒，不给人物无差别铺砂，不以末尾白点代替分层，不画乳白云/霉斑。磨损内容随动，故障层可跳动。
液化先不规则二维大形、有限主色区与深墨；禁止整套HSV色环、等距霓虹细带、发光描边和整屏随机RGB。不得仅降饱和宣称设计完成；故障态可以横向条带，宽窄/长度/分区有变化，不是均匀彩虹细条。
